# Mazi Ke Qisse — مکمل ویب سائٹ پروجیکٹ

## شامل صفحات
Home, About, Contact, Blog, Article, Search, 404, Privacy Policy, Terms, Disclaimer, Cookie Policy

## استعمال
تمام فائلیں ایک ہی folder میں رکھیں اور `index.html` کھولیں۔

## Live کرنے سے پہلے
- `[YOUR DOMAIN]` کو اپنے اصل domain سے بدلیں۔
- `[YOUR EMAIL]` اور social links بدلیں۔
- Contact form کو Formspree/Web3Forms یا اپنے backend سے connect کریں۔
- Newsletter کو اپنے email provider سے connect کریں۔
- اصل تصاویر/لوگو شامل کریں۔
- Privacy/Terms/Disclaimer کو اپنے حقیقی استعمال کے مطابق review کریں۔
- `sitemap.xml` اور `robots.txt` میں domain تبدیل کریں۔

## SEO
Google Search Console میں domain verify کرکے sitemap.xml submit کریں۔

## اہم
یہ static starter project ہے۔ حقیقی CMS، database، user accounts، automated email اور admin panel کے لیے backend/CMS integration درکار ہوگی۔
